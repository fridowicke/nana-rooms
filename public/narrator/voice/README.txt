Put your voice recordings here as .mp3 files.
Name each file after the line id in lines.js, for example:
  home-intro.mp3   about-intro.mp3   room-howto.mp3   obj-tv.mp3
A line without a file is still shown in the bubble; her lips follow the text instead of your voice.
iPhone voice memos are .m4a: convert them to .mp3 (or send them to Claude to convert).
